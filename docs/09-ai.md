# AI System Specification

AI evidence üzerinde synthesis katmanıdır.

Pipeline:
Raw sources → normalization → entity matching → topics → sentiment/claims → evidence aggregation → scoring → AI synthesis → decision.

AI; review, quote, source, price, specification, statistics veya confidence uyduramaz.

Output mümkün olduğunda conclusion, evidence references, confidence, generatedAt, modelVersion ve promptVersion içerir.

Q&A:
short answer → evidence → caveats → confidence → sources.
