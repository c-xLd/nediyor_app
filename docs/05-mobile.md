# Mobile Application Specification

React Native + Expo + TypeScript + Expo Router önerilir. Reanimated, Gesture Handler, TanStack Query, Zustand, FlashList, expo-image, notifications, secure storage ve haptics kullanılabilir.

Mobil web wrapper değildir.

Use bottom sheets, sticky actions, horizontal rails, full-screen search, progressive disclosure, skeletons and optimistic saves.

Cache recent products, searches, categories and watchlist. Cached prices must be marked stale.

Test iOS/Android, small/large screens, large text, dark mode, slow network and offline.
