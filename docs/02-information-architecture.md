# Information Architecture

## Mobile
Home / Explore / Deals / Compare / Watchlist.

## Product
Product → Decision → Evidence → Topics → Reviews → Price → Sources → Alternatives → Questions.

## Navigation
Root destinations use bottom tabs. Secondary screens use contextual back navigation. Search is a global function; Explore is a destination.

## Deep links
Product, search, compare, deals and watchlist must have stable deep links.

## State preservation
Preserve query, filters, scroll, compare selection and unfinished flows when possible.
