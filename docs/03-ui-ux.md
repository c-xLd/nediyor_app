# UI/UX Specification

Her ekran purpose, primary action, hierarchy, loading, empty, partial, error, offline, success, accessibility ve analytics tanımlar.

## Core
Home: search first.
Search: full-screen, autocomplete, natural language.
Product: identity → decision → evidence → price → alternatives.
Compare: 2–4 products; mobile-native horizontal comparison.
Deals: real evidence-backed discounts.
Watchlist: saved products + alerts.
Finder: guided decision flow.
Upgrade: current → target → priorities → differences.

Minimum touch target 44×44pt. Essential actions gesture-only olamaz. AI synthesis ve source evidence ayrıdır. Fake urgency/counters kullanılmaz.
