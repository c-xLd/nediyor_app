# Data Sources & Provenance

Kaynak türleri: e-commerce reviews, forums, communities, videos, complaint platforms, public specs, merchant feeds, community votes.

Source kaydı provider, canonical URL, type, retrieval time, product mapping ve provenance içerir.

Product matching mümkün olduğunda GTIN/EAN/UPC, model number, brand, normalized name ve variant attributes kullanır.

Provider terms, API terms, copyright, privacy ve robots kurallarına uyulur; mümkün olduğunda official API/licensed feed tercih edilir.
